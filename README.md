# Portfolio

https://nk35jk.github.io/

### Launch Server

```shell
hugo server -D
```

Then open `http://localhost:1313`.

### Build

```shell
hugo
```

### Create Page

#### News

```shell
hugo new news/<name>.md
```

#### Blog

```shell
hugo new blog/<name>.md
```
